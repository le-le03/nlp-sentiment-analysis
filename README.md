# 中文文本情感分析系统

## 一、项目概述

本项目为中文文本情感分析系统，基于深度学习技术构建，采用 ChnSentiCorp 中文酒店评论数据集进行训练和验证。系统集成 CNN、LSTM、CNN-LSTM 混合模型，通过加权融合方式提升预测准确率，在测试集上达到 97% 以上的分类准确率。

系统提供标准化 API 接口，支持文本情感自动判别，可应用于客户评论分析、舆情监测、服务质量评价等业务场景。

## 二、技术架构

### 2.1 技术栈

| 类别 | 技术选型 |
|------|----------|
| 开发语言 | Python 3.9 |
| 深度学习框架 | TensorFlow 2.x / Keras |
| 中文处理 | jieba 分词 |
| 特征工程 | TF-IDF、统计特征提取 |
| 接口服务 | FastAPI / Uvicorn |
| 数据处理 | Pandas / Scikit-learn / NumPy |

### 2.2 模型结构

系统采用多模型集成架构：
- **CNN 模型**：利用卷积层提取文本局部特征
- **LSTM 模型**：利用双向循环神经网络捕捉上下文依赖关系
- **Hybrid 模型**：融合 CNN 与 LSTM 优势，兼顾局部特征与长距离依赖
- **集成策略**：基于各模型验证准确率进行加权融合

## 三、实验结果

在 ChnSentiCorp 数据集（共 31580 条样本，正负样本比例约 1:1）上的测试结果：

| 模型 | 准确率 | 精确率 | 召回率 | F1 值 |
|------|--------|--------|--------|-------|
| CNN | 97.18% | 96.80% | 97.60% | 97.20% |
| LSTM | 96.80% | 96.75% | 96.87% | 96.81% |
| Hybrid | 96.85% | 95.69% | 98.14% | 96.90% |
| **集成模型** | **97.37%** | **96.96%** | **97.82%** | **97.39%** |

### 3.1 训练配置

- 训练集：18948 条
- 验证集：6316 条
- 测试集：6316 条
- 词汇表大小：10000
- 嵌入维度：64
- 序列长度：200
- 正则化方法：Dropout (0.5) + L2 正则 + 早停机制

## 五、部署与使用

### 5.1 环境准备

```bash
pip install -r requirements.txt
```

### 5.2 数据准备

将 ChnSentiCorp 数据集（tsv 格式）放置于 `data/` 目录下，系统将自动加载并进行预处理。

### 5.3 模型训练

```bash
python src/main.py
```

训练完成后，模型权重保存于 `models/` 目录，实验报告保存于 `results/` 目录。

### 5.4 启动服务

```bash
python -m uvicorn api.app:app --host 0.0.0.0 --port 8000
```

服务启动后，访问 `http://localhost:8000/docs` 可查看交互式接口文档。
